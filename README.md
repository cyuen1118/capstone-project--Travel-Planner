Abstract:
            
            Travel Planner is a programme designed to assist user preparing travel plan, flight schedule, and providing related suggestion on how to travel from previous attraction to next attraction. Travel Planner has a “Build Itinerary” function, where the programme will based on the input and created a travel schedule with flight details, recommended hotel option, activity and transportation information. Through utilizing the Travel Planner, user could reducing the time spending on research travel information and effectively retrieve the useful information preparing for their trip. 
The Travel Planner is connected with the API, which providing the real time data for flight, hotel, activity recommendation. The user could refer on their preference editing the “Activity Keyword” and “Budget” filter and applying the filter on their itinerary. The activity result will search for activity type and hotel/flight result will search for the option within the budget. For example, the field “Activity Keywords” has keywords “shrine, park, restaurant”, then the itinerary result will include suggested activity related with the keywords. It benefits user retrieve activity based on their preference while still effectively managing their travel itinerary. Travel Planner also implemented with AI and compare the related travel information. The AI recommendation enrich Travel Planner information, and reduce user’s effort doing the comparison.
